### Study roadmap in weeks 

**Weeks 1-2: Fundamentals and Digital Logic** <br/>
Computer fundamentals, number systems, Boolean algebra, gates, K-maps, combinational and sequential circuits.

**Weeks 3-4: Programming and Data Structures** <br/>
C, C++, Java, Python, OOP, stacks, queues, linked lists, trees and graphs.

**Weeks 5-6: DBMS and Operating Systems** <br/>
SQL, normalization, transactions, scheduling, deadlocks, memory management.

**Weeks 7-8: Computer Networks and Software Engineering** <br/>
OSI, TCP/IP, subnetting, protocols, SDLC, testing and maintenance.

**Weeks 9-10: Advanced Computer Science** <br/>
TOC, compiler design, discrete mathematics, algorithms, web technologies and emerging technologies.

**Weeks 11-12: Revision and Mock Tests** <br/>
Full-length tests, PYQ revision, weak-topic analysis and timed practice.
