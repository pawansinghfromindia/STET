# BPSC TRE 4.0 - Complete Guide 

> BPSC TRE 4.0 = Bihar Public Service Commission - Teacher Recruitment Examination.

It is the teacher recruitment process of Bihar's government school. <br/>
BPSC conducts this examination to recruit teachers for government schools across Bihar, from Primary to Senior 
Secondary levels (Classes 1-12). 
- PRT - Primary Teacher, Classes 1-5 
- Middle School Teacher, Classes 6-8 
- TGT - Secondary Teacher, Classes 9-10 
- PGT - Higher Secondary Teacher, Classes 11-12

### 5. Negative Marking

<details>
  <summary> <b> -ve Marking </b> </summary>

<br/>

According to the reported TRE 4.0 examination pattern:
- Correct answer: +1 mark
- Incorrect answer: -1/3 mark
- Unanswered question: 0 mark

Example
```
Suppose you attempt:
- 100 questions
- 80 correct
- 20 incorrect
Calculation: 80 - (20 * 1/3)
           = 80 - 6.67
           = 73.33

Final score = approximately 73.33 marks
```
Therefore, accuracy is important.

</details>
